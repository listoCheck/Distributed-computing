# PA2 — неблокирующий IPC

Программа моделирует банковские переводы между дочерними процессами через
однонаправленные POSIX-каналы. Каждый процесс ведёт `BalanceHistory`, а
родитель запускает сценарий `bank_robbery()` и собирает все истории.

```sh
make                         # рядом должна лежать libruntime.so
./pa2 -p 3 10 20 30
```

Для проверки следует подключить предоставленную преподавателем `libruntime.so`
и запускать с `LD_PRELOAD`, как указано в задании. Во время проверки бот может
заменить `bank_robbery.c` и заголовочные файлы на свои версии.

Архив для отправки создаётся командой `make package`; его имя — `pa2.tar.gz`,
а исходные файлы в нём находятся в каталоге `pa2`.
