# Результаты проверки

Дата локальной проверки: 14.09.2026.

| Среда | Проверка | Результат |
|---|---|---|
| Ubuntu 22.04, Clang 14 | C99, `-Wall -Wextra -Werror -pedantic` | Без предупреждений |
| Ubuntu 22.04, Clang 14 | 100 многопроцессных запусков, полная история, логи | Пройдено |
| Ubuntu 22.04, Clang 14 | 20 запусков с AddressSanitizer и UBSan | Пройдено |
| Ubuntu 14.04, Clang 3.5.0 | C99, `-Wall -Wextra -Werror -pedantic` | Без предупреждений |
| Ubuntu 14.04, Clang 3.5.0 | 100 многопроцессных запусков, полная история, логи | Пройдено |
| Обе версии Clang | C-тест часов, IPC, pending и границы истории | Пройдено |
| Обе среды | Ошибочные аргументы, невозможная длина истории | Ожидаемый ненулевой код |
| Файлы интерфейса | Сравнение четырёх заголовков и `libruntime.so` с лабораторной №2 | Побайтовое совпадение |

Во всех 220 успешных запусках проверялись код 0 и пустой stderr. Каждый запуск использовал библиотеку из `lab2/lab2`, включая `LD_PRELOAD`. История сравнивалась поэлементно с независимой моделью, построенной по временам отправки и получения переводов; состав переводов сверялся с тестовым сценарием.

Набор включает размеры системы 1, 2, 3, 10 и 15 дочерних процессов; кольцевой сценарий и пять подменяемых сценариев с seed 11, 23, 37, 41, 53. В длинных сценариях выполняется до 35 переводов. Проверяются нулевые суммы, пустой сценарий и разные начальные балансы. Повторные запуски дают разные допустимые межпроцессные расписания, но это не исчерпывающий перебор всех расписаний.

Отдельный `probe.c` проверяет нулевые начальные часы, одинаковую отметку multicast, неизменность `const Message`, неполные заголовки и payload, отсутствие тиков при `EAGAIN`, оба случая `max(local, remote) + 1`, круговой обход, неправильный magic, интервал pending длиной 6 и границу 255 состояний.

`tests/check_archive.sh` извлекает именно сдаваемый архив во временный каталог, собирает его с параметрами из PDF и проверяет запуск `-p 3 10 20 30`, пустой stderr и сумму 60 во всех столбцах.

Локальные проверки не являются ответом бота. Скрытый `bank_robbery.c`, антиплагиат и результат защиты здесь не проверялись. Физическая среда исполнения тестов — Docker Desktop/WSL2; Ubuntu и компилятор соответствуют указанным версиям, ядро Linux предоставлено хостом контейнеров.

Ограничение формата: длина истории `uint8_t` допускает состояния 0..254. Время 255, если его требуется сохранить, отклоняется с диагностикой вместо переполнения длины. Подробности приведены в README.
